# MG996R — Controle de Posição

## Objetivo

Controlar um servomotor MG996R pelo ATmega328P (Arduino Uno/Nano), por comandos enviados pelo Monitor Serial.

## Funcionamento

O código utiliza a biblioteca `Servo.h` para solicitar ângulos de 0° a 180°. O MG996R possui controle interno de posição: o ângulo exibido é o **solicitado**, não o medido. Comunicação serial: **115200 baud**, com final de linha **Nova linha**.

## Conexões

| Fio / terminal | Conexão | Função |
|---|---|---|
| MG996R — laranja | Arduino **D12** | Sinal de controle |
| MG996R — vermelho | Fonte externa regulada **5–6 V** | Alimentação do servo |
| MG996R — marrom | GND da fonte e GND do Arduino | Terra comum |

**Atenção:** utilize alimentação externa com corrente suficiente para os picos do servo; não alimente o MG996R diretamente pelo 5 V do Arduino. Confira a tensão admitida pela versão do servo.

## Comandos implementados

| Comando | Função |
|---|---|
| `S1 90` | Solicita 90° ao MG996R |
| `S1 <ANG>` | Solicita ângulo entre 0° e 180° |
| `STATUS` | Exibe o último ângulo solicitado |
| `CENTER` | Solicita a posição de 90° |

## Teste

Sem carga mecânica, envie `S1 90`, `S1 110`, `S1 70` e `STATUS`. Inicie com movimentos pequenos antes de testar os extremos.
